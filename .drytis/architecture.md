## Data Flow
```
Browser (React SPA)
  ↓ fetch /api/*
Caddy (reverse_proxy :8000 for /api/*, serve frontend dist for /*)
  ↓
FastAPI (uvicorn on :8000)
  ├── ai_service → OpenAI-compatible endpoint (OPENAI_BASE_URL)
  ├── imap_service → user's IMAP server
  └── database.py → MySQL (127.0.0.1:3306)
```

## Routing
- `/` → React SPA (dashboard)
- `/inbox` → inbox list
- `/emails/:id` → email detail
- `/follow-ups` → follow-up tracker
- `/analytics` → analytics dashboard
- `/settings` → settings
- All `/api/*` → FastAPI backend
